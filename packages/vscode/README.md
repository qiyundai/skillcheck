# Skillcheck

Source-backed diagnostics for agent skill libraries, using the same engine as the Skillcheck CLI.

Open a repository with SKILL.md files. Deterministic checks require no API key. Configure skillcheck.config.json to declare cross-file compositions or explicitly enable cloud semantic analysis.

Commands: Skillcheck: Recheck Workspace and Skillcheck: Show Diff against Git Baseline.

This initial release provides advisory semantic evidence. Missing context or failed provider requests are incomplete analysis. No diagnostics do not certify agent behavior.
